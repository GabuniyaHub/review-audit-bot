# review-audit-bot

Учебный прототип ВКР: Telegram-бот для сравнительного репутационного аудита своей компании и трёх конкурентов по отзывам из 2ГИС и Яндекс.Карт.

Планируемый стек: NestJS, TypeScript, PostgreSQL, Telegram Bot API, LLM API. Сбор отзывов отделён от анализа; частоты и показатели рассчитывает приложение.

## Текущее состояние
Этап 1 завершён: подготовлены требования, выбран пилот в Тюмени, исследованы сборщики и проверена живая постраничная выгрузка обоих источников. Из 2ГИС отобраны 500 отзывов; по Яндексу проверены 415 отзывов трёх карточек и отклонено включение 50 отзывов несопоставленного филиала «Максима». Сопоставление адресов Брюта также требует окончательного подтверждения. Рабочее приложение и Telegram-бот ещё не реализованы. Команд установки и запуска пока нет.

- [Источники и проверка сборщиков](docs/sources-and-parsers.md)
- [Компании пилота](docs/pilot-tyumen.md)

Кандидат для 2ГИС — ruvn-1fgas/2gis-parser; согласовано некоммерческое использование для ВКР. Это не лицензия на будущий коммерческий сервис. Копирование стороннего кода пока не выполнялось.

## Следующие этапы
Проверка полной выгрузки → основа NestJS/PostgreSQL → команды бота → адаптеры источников → LLM-анализ → сравнение и отчёт → расписание → эксперимент ВКР → развёртывание.
