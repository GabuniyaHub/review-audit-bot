# Репутация — Android-приложение

Мобильная версия review-audit-bot: одна своя компания, до трёх конкурентов, отзывы, анализ тональности и тем, сравнение и отчёт с цитатами. Устанавливается одним APK. Telegram, Node-сервер, PostgreSQL и компьютер для работы приложения не нужны.

## Установка и первый показ

1. Перенесите готовый `reputation-audit.apk` на Android-телефон и откройте его. Разрешите установку из выбранного файлового менеджера, если Android запросит. Нужны Android 8.0+ и актуальный Android System WebView.
2. Откройте приложение **Репутация** → **Открыть учебный пример**.
3. В примере четыре **вымышленные** кофейни Тюмени и 512 демонстрационных отзывов. Это учебные данные, а не выгрузка реальных организаций.
4. На экране **Обзор** нажмите **Анализировать**. Учебный пример первоначально использует **локальный алгоритм без ИИ**: он работает без интернета и прямо так обозначен.
5. Нажмите **Сформировать отчёт**. Покажите средние оценки выборки, тональность, темы, сравнение, рекомендации и цитаты.
6. Кнопка **Сохранить отчёт .md** открывает системное сохранение файла. Файл можно передать преподавателю или открыть в редакторе.

APK не требует запуска сервера на Mac или VPS. Интернет нужен для OpenRouter и получения страниц площадок. Существующие сайты на VPS не используются и не изменяются.

## Настоящий анализ нейросетью

В разделе **Ещё**:

1. Выберите **ИИ · OpenRouter**.
2. Выберите бесплатную модель.
3. Нажмите **Проверить ИИ** — выполняется настоящий запрос на вымышленном отзыве, ответ и цитаты проверяются кодом.
4. Вернитесь в **Обзор** → **Анализировать**.

Модели:

| Модель                                   | Назначение и проверка 20.10.2026                                                                                                                       |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `nvidia/nemotron-3-super-120b-a12b:free` | Исходная модель по запросу пользователя. В каталоге есть, однако проверка получила HTTP 404 от провайдера NVIDIA. Не считать исправным ответом.        |
| `nvidia/nemotron-3.5-lightning:free`     | Согласованная запасная бесплатная модель. Получены реальные ответы HTTP 200, проверены JSON, ID и соответствие цитат. Выбирается вручную в настройках. |

Платных моделей и скрытой автоматической подмены нет. В сохранённом отчёте записываются фактически выбранные режим и модель. После переключения модели результаты другой модели не выдаются за актуальные: нужные отзывы анализируются заново.

Запросы идут **напрямую с телефона** в `https://openrouter.ai/api/v1/chat/completions`. Локально модель NVIDIA не запускается: это удалённый API. Бесплатный провайдер может быть недоступен, отвечать медленно или выдавать 403/404/429. Сообщение об ошибке видно в приложении и истории. Сервер или локальный алгоритм не подставляются вместо ответа ИИ.

За один запрос отправляются до восьми текстов, между пакетами есть пауза. После каждого успешного пакета результат сохраняется в SQLite. Операцию можно остановить и продолжить без повторного анализа уже сохранённых текстов. Закрытие приложения прерывает работу, но завершённые пакеты остаются. Фоновое выполнение и ежедневное расписание в мобильной версии не реализованы.

В локальную APK-сборку включён предоставленный пользователем ключ. Он **не закоммичен**: хранится в игнорируемом `android/secrets.properties`, при сборке создаётся игнорируемый Java-класс. Новый ключ можно указать в приложении без пересборки. Ключ не экспортируется в резервную копию, не отображается в интерфейсе и не выводится в журнал. Вшитый в APK ключ технически извлекаем: эта сборка предназначена для личного учебного показа, а не публикации в магазине.

## Компании, реальные отзывы и импорт

**Компании** → **Добавить свою компанию**, затем до трёх конкурентов. Обязательны название и город. Адрес, полные ссылки на Яндекс.Карты/2ГИС и подтверждение филиалов вводятся отдельно. Без карточек можно работать через импорт JSON.

Сбор выполняется только для подтверждённых карточек:

- **Яндекс**: приложение запрашивает публичную страницу конкретной организации и извлекает отзывы из её состояния. Это **частичная выборка одной страницы**, а не гарантированная выгрузка всех отзывов. CAPTCHA, запрет доступа и изменение разметки показываются как ошибка. `updatedTime` не выдаётся за дату публикации.
- **2ГИС**: текущая мобильная версия не обеспечивает надёжную автоматическую выгрузку. Площадка может выдать CAPTCHA, а её публичная страница не даёт стабильного мобильного API отзывов. Предусмотрен импорт. Автоматического обхода защиты нет.

**Отзывы** → **Импорт JSON**. Выберите файл в системном файловом менеджере, затем компанию для строк без `companyId`. Пример готового файла: [android/examples/reviews-import.json](android/examples/reviews-import.json).

Формат:

```json
{
  "reviews": [
    {
      "text": "кофе вкусный, но заказ ждал долго.",
      "rating": 3,
      "source": "import",
      "externalId": "review-1",
      "publishedAt": "2026-10-19T10:00:00Z"
    }
  ]
}
```

Также принимается массив без обёртки. Допустимы источники `import`, `yandex`, `2gis`, `demo`; неизвестное значение сохраняется как импорт. `companyId` — ID компании внутри приложения, можно не указывать и выбрать компанию при импорте. Необязательны `rating` (1–5 или null), `publishedAt` (ISO 8601), `externalId`, `url` (HTTPS-ссылка на поддерживаемую площадку).

Ограничения: файл до 5 МБ, до 2000 отзывов за обычный импорт, до 5000 в проекте, текст до 12 000 символов. Перед применением проверяется весь файл. Импорт без ошибок не приводит к частичному добавлению. Дедупликация учитывает компанию, источник и внешний ID, а при его отсутствии — нормализованный текст. Изменение текста сбрасывает его анализ. Совпадения текста между источниками помечаются и отражаются в предупреждениях отчёта.

Фильтры: компания, источник, тональность и поиск по тексту. Отзывы отображаются по 30, следующие загружаются кнопкой. Авторов приложение не сохраняет.

## Отчёты и хранение

- SQLite находится в приватном каталоге приложения на телефоне. Ни GitHub, ни серверу база не передаётся.
- Сохраняются компании, отзывы, выбранный режим и модель, результаты анализа, события и до 20 отчётов-снимков.
- Обычный повторный запуск и обновление APK с той же подписью сохраняют базу. Удаление приложения удаляет данные.
- Средние оценки, количество отзывов, покрытие анализом и доли вычисляет код. Нейросеть определяет тональность и темы, но не подменяет арифметику.
- Для каждой темы проверяется точная цитата из отправленного текста. Неизвестные ID, неподтверждённые цитаты и неверный JSON не сохраняются.
- Указывается фактическое покрытие, малая выборка, неизвестные даты, присутствие демонстрационных данных и ограничения источников.
- Рекомендации строятся по найденным негативным/смешанным темам своей компании и сопровождаются цитатами. Это правила принятия решений по результатам анализа, не отдельный ответ LLM.
- Фильтр периода применяется одинаково ко всем компаниям. Неизвестные даты исключаются. Пустые даты означают всю доступную выборку.

**Ещё** → **Сохранить копию JSON**: файл включает компании, отзывы, анализ и снимки отчётов, но не API-ключ. **Импорт / восстановление** принимает такую копию и восстанавливает компании, отзывы и проверенный кэш анализа. Для безопасности импортированные численные отчёты не принимаются на веру: сформируйте отчёт заново после восстановления. Восстановление заменяет текущий проект после подтверждения. Учебная копия для проверки: [android/examples/demo-backup.json](android/examples/demo-backup.json).

Перед отправкой в OpenRouter код маскирует контакты, ссылки и слова с заглавной буквы. Маскировка эвристическая, не гарантированная анонимизация. Не используйте персональные и конфиденциальные сведения: бесплатный endpoint NVIDIA ограничивает такие данные. В интерфейсе и документации локальный алгоритм не называется нейросетью, а вымышленные отзывы — реальными.

## Сборка APK из исходников

Нужны macOS/Linux, Node.js 22+, JDK 17+ и Android SDK с **Platform 35** и **Build Tools 36.0.0**. Gradle, npm-зависимости старого бота и PostgreSQL для Android-сборки не нужны. Внешних Android-библиотек нет.

```sh
cp android/secrets.properties.example android/secrets.properties
# В android/secrets.properties добавить OPENROUTER_API_KEY.
# Либо задать переменную окружения OPENROUTER_API_KEY для сборки.

export ANDROID_SDK_ROOT="$HOME/Library/Android/sdk"
export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"
bash android/build.sh
```

Результат: `android/build/reputation-audit.apk`. Для Linux укажите свои пути SDK/JDK. Поле `BUILD_TOOLS` при необходимости задаёт другую установленную версию инструментов. Не копируйте файл-пример поверх существующего файла с ключом.

Первый запуск сборки создаёт локальное `android/demo.keystore` с учебной подписью. Сохраните его для последующих обновлений APK. Он исключён из Git, поэтому новый клон создаст другую подпись; Android не установит обновление с другой подписью поверх существующего приложения. Перед удалением старого приложения сделайте резервную копию данных.

Установка через USB при настроенной отладке:

```sh
adb install --no-incremental -r android/build/reputation-audit.apk
```

## Проверки

```sh
node --test android/tests/*.test.mjs
bash android/build.sh
# Только на отдельном тестовом эмуляторе, база этого приложения будет сброшена:
ANDROID_SERIAL=emulator-5554 bash android/test-device.sh
# Настоящий запрос к OpenRouter, ключ берётся из локального файла:
LLM_MODEL=nvidia/nemotron-3.5-lightning:free node android/scripts/check-openrouter.mjs
```

Тесты проверяют 512 учебных отзывов, дедупликацию, сброс устаревшего анализа, проверку цитат, правильное разделение моделей/режимов, период, расчёты и обработку неправильного импорта. Android-тест дополнительно проверяет запуск APK, мост WebView↔Java, настоящую SQLite, сохранение после пересоздания Activity, мобильную навигацию и запрос к запасной модели из Android. Тестовый APK не нужен для использования приложения и не входит в пользовательскую сборку.

Проверка 512 синтетических отзывов не доказывает точность модели на реальном корпусе и не подтверждает ориентир ВКР «500 реальных отзывов за 10 минут». Для такой оценки нужен отдельный реальный корпус, независимая разметка и замер реального полного цикла.

## Структура и прежняя версия

- `android/app/src/main/java/ru/reputation/audit` — Activity, приватная SQLite, HTTPS, OpenRouter и сборщик.
- `android/app/src/main/assets` — мобильный интерфейс и проверяемая логика нормализации, анализа и отчёта. Интерфейс встроен в APK и не загружается с сайта.
- `android/tests` — тесты расчётов и инструментальный Android-тест.
- `android/examples` — файлы для импорта и восстановления.
- Старые `src`, `test`, `tools`, `deploy` и npm-команды относятся к прежней Telegram/NestJS-версии. Для APK они не запускаются. Её архивная инструкция: [docs/telegram-legacy.md](docs/telegram-legacy.md). Это не описание текущей серверной установки.

В исходном документе ВКР указаны Telegram/NestJS/PostgreSQL. Для описания этой версии архитектуру и пользовательские сценарии нужно актуализировать: Android, локальная SQLite и прямой HTTPS-вызов OpenRouter.
