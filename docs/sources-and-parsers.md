# Проверка источников и готовых сборщиков

Дата: 16.10.2026. Проверены документация и исходники. Наличие кода не означает подтверждённую полную выгрузку 500 отзывов.

## Официальные интерфейсы
- 2ГИС Places API: фильтр has_reviews есть, получение текстов отзывов этим методом не поддерживается: https://docs.2gis.com/api/search/places/examples/filtering
- Яндекс: подтверждён виджет для отображения отзывов, он не является подтверждением API массовой выгрузки: https://yandex.ru/dev/maps/mapstools/
- API Яндекс Маркета относится к товарам, не заменяет отзывы организаций в Картах.

## Выбранный кандидат 2ГИС
https://github.com/ruvn-1fgas/2gis-parser
Коммит 74954b5; дата коммита 19.03.2026. Пользователь согласовал некоммерческое использование для ВКР.
LICENSE.md разрешает личное, образовательное и исследовательское использование, изменения распространяются на тех же некоммерческих условиях. Использование в коммерческом сервисе запрещено условиями автора. При включении кода сохранять лицензию и происхождение.
Код: Python/Scrapy; сбор организаций, отзывов и экспорт JSON/XLSX. Для четырёх карточек не нужны массовый обход городов, медиа и меню: адаптировать только сбор отзывов.
Текущий сбор отзывов обращается к public-api.reviews.2gis.com с limit/offset и встроенным ключом клиента. Это интерфейс, используемый сторонним сборщиком, а не гарантированная поддержка стандартного Places API. Работоспособность и допустимый режим доступа проверяются отдельно. Не выводить ключ в отчёты и логи; лицензия кода не выдаёт дополнительных прав к API площадки.
Пробный HTTP-запрос ограничен пятью отзывами для каждого из четырёх филиалов. Результат и ошибки записаны в 2gis-probe-results.json. Полную пагинацию и достижение 500 отзывов этим тестом не подтверждаем.

2. https://github.com/MironBerch/ymrp — ed12ae4, 28.12.2025. Apache-2.0; Python >=3.12 по pyproject. В ymrp/parsers/reviews.py базовый класс YandexMapParser используется без импорта из base.py; аналогичная проверка нужна модулю товаров. Браузер запускается headless=False; цикл раскрытия текстов имеет условие `iterations < 10 or len(more_buttons) != 0`, без гарантированного верхнего предела при застрявшей кнопке. Ошибки отдельных отзывов пропускаются. Кандидат на доработку, не подтверждён как готовое решение.

Метаданные composer.json указывают MIT, отдельного LICENSE в checkout не найдено; перед копированием уточнить область действия. Перехват fetchReviews и DOM-резерв; ограничение 30 прокруток, возможные пустые ID; не гарантирует полную выгрузку. Весь Laravel-проект не нужен для NestJS.

## Следующий эксперимент
Для 2ГИС проверить поля и уникальность IDs, две страницы пагинации, повторный запрос, ошибки 403/429 и отсутствие пропусков; затем ограниченная выборка 125 текстовых отзывов на филиал, если доступны. Для Яндекса выбрать и исправить отдельный сборщик, проверить точное соответствие филиалов, даты, рейтинг, полный текст, ссылки и границы загрузки. Не считать поисковый кэш результатом живой выгрузки. При CAPTCHA остановить задачу со статусом, без автоматического обхода.

## Результат живой проверки 16.10.2026
Проверка выполнена отдельным небольшим HTTP-пробником по шаблону URL выбранного репозитория: сам Scrapy-проект не устанавливался и целиком не запускался. Для каждого из четырёх филиалов успешно получены три страницы по 50 отзывов (offset 0/50/100). На каждом филиале 150 разных ID с непустыми текстами; для пилота оставлены первые 125. Итого выбраны 500 отзывов. У всех выбранных отзывов есть ID, текст, оценка и дата создания. Получение страниц по всем компаниям заняло примерно 21 секунду, включая задержки между запросами; это не время LLM-анализа или полного аудита.

В поле url индивидуальная ссылка присутствовала только у 8 из 500 отзывов. Поэтому отчёт должен сохранять sourceReviewId и карточку филиала, не выдавать ссылку на карточку за точную ссылку на отзыв. Полные тексты сохранены локально в work/probes, в Git не добавлялись. Протокол без текстов и авторов: 2gis-pagination-results.json.

Результат подтверждает пригодность метода выгрузки выбранного кандидата на текущих четырёх карточках. Не подтверждает бессрочную доступность интерфейса, запуск всего Scrapy-проекта, корректность нормализации дат и устойчивость к смене API. Остаются отдельные проверки повторного сбора и обработки ошибок. TLS проверялся с системным хранилищем CA; проверка сертификатов не отключалась.
