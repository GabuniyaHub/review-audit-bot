# Этап 5: семантический анализ отзывов

Реализованы OpenRouter-клиент и PostgreSQL-очередь анализа, команда `/analyze`, состояние `/status`, проверяемый JSON-контракт. Модель по умолчанию `nvidia/nemotron-3-super-120b-a12b:free`. Реальные ответы модели и качество русскоязычного анализа пока не подтверждены: запросы с сервера 16.10.2026 возвращают HTTP 403: `Access denied by security policy.` Даже GET /api/v1/key возвращает этот ответ, поэтому исправность ключа установить не удалось. Ограничение не обходилось.

## Настройка

В существующий .env добавить:

```
ANALYSIS_ENABLED=true
LLM_MODEL=nvidia/nemotron-3-super-120b-a12b:free
LLM_TIMEOUT_MS=90000
ANALYSIS_BATCH_SIZE=5
```

Секрет — `LLM_API_KEY` либо `OPENROUTER_API_KEY` (последний имеет приоритет). После миграции и сборки `node tools/check-llm.mjs` проверяет доступ на двух вымышленных отзывах; рабочие тексты и БД для проверки не используются. До устранения HTTP 403 держать ANALYSIS_ENABLED=false.

## Поведение

- `/analyze` выбирает до 1000 новых текстовых отзывов текущего проекта пользователя и сохраняет снимок ID/contentHash в analysis_run_items. Пустые отзывы и тексты длиннее 12000 символов не отправляются. Для следующей порции повторить команду после окончания.
- Один активный аудит на проект; повторная команда не создаёт дубль. Пакет по умолчанию 5 отзывов, параллельный worker один на процесс; распределённый захват FOR UPDATE SKIP LOCKED, lease 3 минуты. После сбоя максимум 3 попытки, успешно сохранённые пакеты повторно не отправляются. 403 и неверный JSON не повторяются автоматически.
- Для каждого отзыва: общая тональность positive/negative/neutral/mixed и до 8 тем с отдельной тональностью и точной цитатой. Темы: продукт, обслуживание, ожидание, цена, атмосфера, чистота, доступность, прочее. Звёзды не передаются модели.
- Ответы проходят проверку обязательных и лишних полей, допустимых значений, уникальных ID/тем, соответствия цитат входным текстам. Выдуманные ID и цитаты отклоняют весь пакет; частичные результаты предыдущих пакетов сохраняются. Существование цитаты не доказывает правильность интерпретации модели.
- Результат кэшируется по ID отзыва + contentHash + model + promptVersion + schemaVersion. Изменение текста/оценки требует нового анализа. Версии фиксируются в audit_runs. Изменения во время запроса не прикрепляют старый анализ к новому тексту и помечают запуск partial.
- Статусы, количество и код ошибки доступны через /status. Завершение ставит одно уведомление в существующий Telegram outbox. Полный сравнительный отчёт и рекомендации относятся к этапу 6.

## Передача данных

Имена авторов, URL источников, звёзды и метаданные организаций в запрос не включаются. Перед отправкой выполняется локальная эвристическая маскировка email, ссылок, телефонов, @упоминаний и слов с заглавной буквы. Она консервативна, может удалить полезные слова и НЕ гарантирует удаление всех персональных данных (например, имён со строчной буквы). Для бесплатного endpoint, запрещающего персональные сведения, перед реальным анализом нужно проверить обезличенность корпуса. В тестовом запросе используются только вымышленные предложения. Текст отзывов обозначен в системном промпте как недоверенные данные; JSON проверяется приложением. Промпт не гарантирует защиту от всех смысловых манипуляций.

## Проверка качества, пока не выполнена

После восстановления доступа: проверить 30–50 вручную размеченных обезличенных отзывов, включая смешанные, негативные, короткие и попытки инструкций внутри текста. Измерить macro-F1 тональности, precision/recall тем, точность цитат, долю валидного JSON, задержки и расходы. Порог качества согласовать до настройки промпта. Для ВКР затем расширить контрольную выборку до 100. HTTP- и PostgreSQL-тесты не заменяют эту оценку.

## Результаты проверки и размещение 16.10.2026

23 модульных теста и 12 PostgreSQL-проверок прошли. Проверены очередь, кэш, повторный анализ изменённых отзывов, восстановление после истёкшей аренды, отклонение выдуманных цитат и сохранение частичного результата. Это проверки инфраструктуры с подменённой моделью, а не метрики качества Nemotron.

Код установлен в /opt/review-audit-bot, миграции 003_collection и 004_analysis применены к существующей базе review_audit. Созданы закрытые резервные копии базы, env и прежней сборки. Ключ сохранён, ANALYSIS_ENABLED=false. Тест нового клиента на вымышленных текстах возвращает access_denied; OpenRouter ранее ответил 403 Access denied by security policy. Версия кода 580aa61. Бот /health/ready и оба действующих сайта отвечают HTTP 200. Автоматических перезапусков службы нет. Свободно около 462 МБ диска, память службы около 97 МиБ.
