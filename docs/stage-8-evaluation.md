# Этап 8 — эксперимент ВКР: выполненная часть и открытые пункты

16.10.2026 подготовлены инструменты и контрольная выборка. Полная оценка качества не завершена: независимая ручная разметка ещё не сделана, пороги качества не согласованы.

## Доступные данные

Проверен локальный архив ранее полученных ответов: 500 текстовых отзывов 2ГИС (125 на каждый из четырёх филиалов) и 50 Яндекс.Карт для Garden. Всего 550 уникальных ID источников, 549 различных текстов до дополнительного обезличивания. Это исторические записи, а не доказательство работающего свежего сбора. Между источниками возможны повторы; автоматически не считать все наблюдения независимыми.

Подготовлено 100 примеров: по 25 на организацию, внутри групп учитываются источник и оценка; 93 из 2ГИС и 7 из Яндекса. Яндекс представлен только Garden: сбалансированный эксперимент по двум источникам и всем четырём организациям пока невозможен. Сопоставление некоторых Яндекс-филиалов остаётся отдельным ограничением из пилотного исследования.

Детерминированная выборка vkr-holdout-v1 формируется по хешу ID, одинаковые обезличенные тексты не повторяются. Имена авторов не экспортируются, текст проходит эвристическую маскировку. Ручная проверка обезличивания обязательна перед внешней отправкой. Тексты контрольной выборки не добавлены в Git; пользовательские артефакты находятся в outputs.

## Инструменты

```
npm run build
node tools/evaluate.mjs prepare input.json directory
node tools/evaluate.mjs score reference.json predictions.json metrics.json
```

Исходный input.json — массив {id,organization,source,rating,text}. prepare создаёт reference.json с пустыми expected.sentiment и expected.topics, а также manifest.json. Разметка выполняется независимо от ответов модели. score принимает результаты JSON-контракта бота и вычисляет:

- macro-F1 по четырём фиксированным классам тональности, precision/recall/F1 и поддержку каждого класса, матрицу ошибок;
- micro precision/recall/F1 тем и показатели каждой темы;
- долю валидных ответов, число пропусков/ошибок, долю точных цитат.

Отсутствующие классы имеют нулевой F1 и входят в macro, поэтому обязательно учитывать поддержку. Пропущенные и невалидные ответы остаются в знаменателе. Незаполненный эталон и неизвестные/повторные ID отклоняются. Проверка цитат доказывает присутствие текста, а не правильность темы или рекомендации. Независимость разметчика нельзя установить программно.

## Что действительно проверено

34 модульных теста и 14 PostgreSQL-проверок прошли. Вычислитель метрик проверен на заранее заданных тестовых результатах, включая пропуски, выдуманные цитаты, повторные ID и пустые метки. Это проверка формул, не достигнутое качество Nemotron.

Ранее на Mac реальная модель обработала 8 вымышленных отзывов и отчёт сформировал 3 действия за 52.2 секунды. Это демонстрация совместимости, не метрика на реальных данных и не замер полного холодного цикла. PostgreSQL-тесты подтвердили дедупликацию повторного сбора, кэш анализа и повторную выдачу отчёта.
