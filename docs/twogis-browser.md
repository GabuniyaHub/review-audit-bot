# Браузерный сбор 2ГИС

Включение: `TWOGIS_MODE=browser`, `COLLECTION_ENABLED=true`.
По умолчанию при отсутствии TWOGIS_MODE сохраняется прежний режим api.
Ключ TWOGIS_REVIEWS_KEY в браузерном режиме не используется.
После установки npm-зависимостей установите Chromium от имени пользователя сервиса:

```
npx playwright install chromium
```

На Ubuntu могут потребоваться системные библиотеки (`npx playwright install-deps chromium`).
Браузер требует существенно больше памяти, чем HTTP-сборщик: на текущем маленьком сервере сначала проверить свободную память и совместимость ограничений systemd. Это изменение само по себе не обновляет сервер.

Сбор запускается через существующую команду /collect после подтверждения карточки.
Открывается публичная страница точного филиала. Кнопка «Загрузить ещё» нажимается последовательно до лимита; изменение DOM проверяется после каждого нажатия. Браузер закрывается при завершении, отмене и ошибке; общий предел запуска 180 секунд. CAPTCHA не обходится. Ошибки страниц не выдаются за успешный пустой результат.

Учтены оба варианта карточки отзыва, заполненные и серые звёзды, полный DOM-текст без ответов организации. Дата интерфейса сохраняется в rawDate: она может обозначать редактирование, поэтому publishedAt остаётся неизвестной. DOM-классы площадки могут измениться; это приведёт к ошибке layout_changed. Без публичного ID используется существующий хеш текста, оценки и даты: изменённый отзыв может стать новой записью; два полностью одинаковых отзыва могут объединиться. Это ограничение следует учитывать при анализе.

Реализация написана для текущего NestJS-проекта самостоятельно по проверенной структуре страницы. Исходный for-what-or не копируется и его Telegram-уведомления не запускаются.

Проверки: unit-тесты DOM (ответы организации, серые звёзды, смена структуры, недопустимые адреса), существующие проверки очереди/БД и отдельный запуск на Garden, Малыгина 90, Тюмень.

Результат 16.10.2026: unit 18/18, PostgreSQL integration 11/11. Отдельный Chromium получает HTTP 200 со страницей «2GIS Captcha», поэтому автоматический сетевой сбор НЕ подтверждён. Ранее встроенный браузер загрузил 100 отзывов. Продуктивное включение требует повторной проверки из среды сервера; CAPTCHA автоматически не решается.
