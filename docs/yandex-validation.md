# Яндекс.Карты: живая проверка выгрузки

Дата: 16.10.2026. Проверка выполнена собственным ограниченным HTTP-пробником `tools/probe_yandex.py`, без копирования чужого кода. Сторонние репозитории изучены как кандидаты, но не установлены как зависимости.

## Метод
Загрузка публичного HTML `/maps/org/<slug>/<id>/reviews/?page=N`; разбор JSON в `script.state-view`; извлечение `reviewResults.reviews` только из карточки с требуемым ID. Не используется предполагаемый неподписанный fetchReviews API. TLS-проверка включена, CAPTCHA не обходится. На карточку не более трёх страниц, 25 секунд на запрос, задержка между страницами. Это диагностический инструмент, не готовый промышленный адаптер.

| Компания | Яндекс ID | Адрес из живой карточки | Новые уникальные ID по страницам | Всего |
|---|---|---|---|---|
| Garden Coffee | 35702680521 | Малыгина, 90 | 50 / 50 / 50 | 150 |
| Кофе Брют | 130058052929 | Советская, 55 | 50 / 50 / 50 | 150 |
| Optimist Coffee | 130207180834 | Республики, 58 | 50 / 50 / 15 | 115 |
| Максим, кандидат | 1085996169 | Семакова, 19 | 50, далее остановка | 50, исключены из сравнения |

У всех полученных записей есть reviewId, непустой текст, rating и updatedTime. updatedTime нельзя автоматически называть датой создания: это дата обновления. Для подтверждённой даты публикации адаптеру нужен отдельный разбор datePublished. Между проверенными страницами повторяющихся ID не было. Результат не подтверждает выгрузку всех отзывов площадки: для Garden и Брюта остановились на установленном лимите.

Получено 465 уникальных ID в пределах соответствующих карточек, из них 415 относятся к трём отобранным кандидатам пилота; 50 «Максима» не включать в аудит Республики, 24 без дополнительного подтверждения. Для Брюта в 2ГИС адрес Советская, 55/1, в Яндексе Советская, 55 (помещение 1 в описании поисковой карточки). Сопоставление вероятно, но для production необходимо подтвердить координаты/контакты, а не только совпадение улицы. Garden и Optimist совпадают по улице и номеру дома. Проверка имени филиала по фрагменту адреса в пробнике — вспомогательный сигнал, не окончательная идентификация.

Публичный поиск Яндекс.Карт по «Максим Тюмень Республики 24» также вернул Семакова, 19. Это не доказывает тождество филиалов и не доказывает отсутствие отдельной карточки. Решение для следующего этапа: оставить источник «Максима» несопоставленным, подтвердить его по координатам/контактам либо заменить учебный филиал после проверки обеих площадок.

## Воспроизведение
```
python3 tools/probe_yandex.py --output yandex-probe-results.json
```
Если локальный Python не видит системный CA на macOS:
```
SSL_CERT_FILE=/etc/ssl/cert.pem python3 tools/probe_yandex.py --output yandex-probe-results.json
```
Протокол содержит только метаданные и счётчики. Тексты и авторы не сохраняются этим инструментом. Собранная выборка не отправлялась в LLM.

## Решение этапа 1
Техническая возможность постраничной выгрузки обоих источников подтверждена на живых ответах. Для 2ГИС используется выбранный некоммерческий кандидат; для Яндекса предлагается собственный HTTP-адаптер начального состояния страницы, с отдельной ошибкой при изменении разметки и CAPTCHA. Запасной браузерный сборщик пока не требуется. Полный бот, нормализация, регулярный сбор, LLM-анализ и устойчивость — последующие этапы, не результаты этой проверки.
